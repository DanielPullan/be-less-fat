Add or change users with a CSV

To add people, fill in the blank CSV: one row per person, and yes under each role they should have. To change people, download all users, edit their rows and upload it again. Rows are matched to accounts by account_id; new people are created, and existing ones are changed to match their row. Rows you delete from the file are left as they are. If any row has a problem, nothing is changed and you're told what to fix.

What goes in each column
  • account_id: filled in for everyone in the download; it's how rows are matched to accounts, so leave it as it is. Leave it blank for new users (rows without one are matched by username).
  • username: the sign-in name, 3–50 letters, numbers, dots, dashes, underscores or @. Change it here to rename an account; their history stays with them.
  • full_name (optional): {{ settings.FULL_NAME_HELP|default("shown instead of their username where it's set.") }}
  • email (optional): also works as a sign-in name, so it must be unique. No emails are sent.
    • {% set locked = locked_roles() %}{% for code, r in role_defs_all().items() %}
  • {{ code }}: {{ r.label }}. {{ r.summary }}.{% if code in locked %} (you can't give or remove this one){% endif %}
    • {% endfor %} {% include ['_account_csv_help.html', 'kanto/_empty.html'] %}
  • active (optional): no disables the account and signs them out; yes enables it. Blank leaves it as it is (new accounts start enabled).
  • first_password (optional): at least 12 characters. For a new user, leave it blank and one is made, shown once afterwards. For an existing user, it replaces their password. Either way they must choose their own when they next sign in.
  • reset_password (optional): yes gives an existing user a new temporary password, shown once afterwards.
  • sign_out (optional): yes signs them out everywhere.
  • two_step and last_sign_in: in the download for information only. They're ignored when you upload.

Leave a whole column out of the file and it isn't changed for anyone. In the {{ account_fields().csv_blank_note }}, a blank cell means none, so download all users first rather than starting from the blank file to change people.
